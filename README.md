# S&P Retailer Club

A modern Next.js web application for S&P Healthcare Retailer Club and loyalty rewards program.

## Features
- **Modern App Router**: Built with Next.js 15, React 19, and TypeScript.
- **Retailer Rewards**: Showcase of retailer programs, coin benefits, and member perks.
- **Product Portfolio**: Interactive showcase of healthcare, intimate wellness, and nutritional ranges.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To create a production build:

```bash
npm run build
```
